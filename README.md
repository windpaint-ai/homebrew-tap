# windpaint-ai/homebrew-tap

Homebrew tap for [Windpaint](https://windpaint.ai) tools.

```sh
brew install windpaint-ai/tap/windpaint
```

Casks in `Casks/` are generated by the release pipeline. Binaries come from
[windpaint-ai/cli releases](https://github.com/windpaint-ai/cli/releases).
Docs: https://docs.windpaint.ai/cli/install
